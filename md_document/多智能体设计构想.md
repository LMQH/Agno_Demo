# Agno 多智能体系统设计说明（地缘政治领域）

## 目标说明

本文档用于说明在地缘政治分析场景下，如何基于 **Agno 架构**设计一个真正具备“自主性、协作性与自我反思能力”的多智能体系统，重点涵盖：

1. 四类核心 Agent 的 system instructions 设计思路  
2. 多立场讨论的回合控制协议（防止无穷争论）  
3. Router Agent 的安全与风险控制策略  

---

## 一、四类 Agent 的 system instructions 精炼思路（地缘政治专用）

### 1. Router Agent（治理与分流中枢）

#### 角色定位
Router Agent 并非“意图识别器”，而是整个系统的**治理与决策中枢（Executive Control）**。

#### 核心职责
- 判断问题复杂度（是否存在立场冲突、意识形态对立）
- 判断风险等级（是否高度敏感、是否可能诱导极端行为）
- 决定处理路径：
  - 直接工具执行
  - 进入多智能体讨论
  - 降级处理
  - 拒绝处理

#### system instruction 设计重点
- **不参与观点生成**
- **必须解释决策理由**
- **只决定“谁来处理、如何处理”，不决定“结论是什么”**

---

### 2. 讨论团队 Agent（保守派 / 激进派 / 官方叙事）

#### 核心设计理念
> 不是“多角色回答”，而是**多套稳定叙事机制的对抗与暴露**。

#### 关键特征
- 每个 Agent 代表一套固定立场与世界观
- 不追求中立
- 不负责最终结论
- 必须回应其他立场的核心论点

#### system instruction 应明确
- 立场边界（能说什么 / 不能说什么）
- 关注焦点（秩序、安全、变革、合法性等）
- 推理偏好（风险规避 vs 道义优先）

> 这些 Agent 的价值在于**制造张力，而不是消除分歧**。

---

### 3. Eval Agent（系统反思者）

#### 角色定位
Eval Agent 是系统的**元认知与自我纠错机制**。

#### 评估维度
- 讨论是否充分
- 是否存在系统性盲区
- 是否被单一叙事主导
- 是否还有新增信息产生的可能性

#### system instruction 关键约束
- **禁止生成最终回答**
- 不输出简单分数
- 输出内容仅限：
  - 问题诊断
  - 改进建议
  - 是否需要回退或终止讨论

---

### 4. Reply Agent（裁决与整合者）

#### 角色定位
Reply Agent 是最终对用户负责的**结构化裁决者**。

#### 核心职责
- 整合多 Agent 的结果
- 明确区分：
  1. 事实共识
  2. 立场分歧
  3. 不确定性与未来变量
- 避免制造“虚假中立”

#### system instruction 重点
- 不站队
- 不抹平分歧
- 明确告诉用户哪些结论依赖立场假设

---

## 二、多智能体讨论回合控制协议（防止无穷争论）

### 核心原则
> **讨论的目标不是说服，而是暴露信息与分歧。**

当新增信息耗尽时，讨论必须终止。

---

### 1. 讨论终止条件（由 Eval Agent 判断）

满足任一条件即可终止讨论：
- 所有立场的核心论点已明确提出
- 新一轮讨论未引入新事实或新视角
- 分歧已被清晰结构化，无法进一步缩小

---

### 2. 讨论权限控制

- 并非每一轮都允许所有 Agent 发言
- Eval Agent 可指定：
  - 某一立场重点回应特定质疑
  - 要求回应失败则终止讨论

---

### 3. 硬性回合上限（系统兜底）

- 设置最大讨论轮次（如 2–3 轮）
- 超过上限后强制进入 Reply Agent

> 这是系统治理约束，不是对 Agent 自主性的削弱。

---

## 三、Router Agent 的拒绝与降级处理策略（安全 / 风险控制）

### 1. 必须直接拒绝的问题类型

Router Agent 应终止并解释拒绝原因的情形包括：
- 明确鼓动暴力、战争、清洗、报复
- 明确要求攻击特定国家、族群或群体
- 将现实冲突道德化、正当化为暴力行动

> 这些属于动员性话语，而非分析性问题。

---

### 2. 应降级处理的问题类型

典型示例：
- “某国是否应该对另一国动武？”

处理方式：
- 不进入讨论团队
- 不允许“应该 / 必须”式结论
- 转为描述性分析：
  - 各方立场
  - 潜在风险
  - 历史案例与后果

---

### 3. 高不确定性问题的处理

包括：
- 依赖未证实情报
- 传闻、阴谋论
- 要求精确预测具体行动或时间

Router 可采取：
- 限制回答范围
- 明确不确定性
- 禁止讨论团队进行推测性对抗

---

## 四、总结性判断

> 本系统的设计重点，不是“多写几个 Agent”，  
> 而是**为观点冲突系统建立治理结构与宪法机制**。

在地缘政治领域：
- Agno 的优势在于自主决策与多立场协作
- 多智能体系统的价值在于暴露分歧，而非制造统一答案
- Router 与 Eval 是系统理性与安全性的关键

---

## 附注

当系统的决策权主要存在于 Agent（而非 Python 流程）中时，  
该系统才是真正意义上的 **Agentic System**。
